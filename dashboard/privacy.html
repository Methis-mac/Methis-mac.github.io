Privacy policy

Last updated 17 October 2026

Henry's Dashboard ("the app") is a personal, single-user app that runs on its owner's own computer. Its only user is its owner. This policy explains what Google data the app accesses and what it does with it.

Data the app accesses

  • Google Drive (only files the app creates). The app creates one spreadsheet of investment holdings in the owner's Google Drive and reads it to show a portfolio summary. Using Google's drive.file permission, it cannot see or open any other files.
  • Gmail (read-only), if enabled. The app may read the sender, subject and a short snippet of unread or flagged messages to show an inbox summary. It never reads or stores full message bodies, and it never sends, changes or deletes email.

How the data is used and stored

  • Data is used only to display the owner's own dashboard to the owner.
  • Data is processed and stored only on the owner's own computer. The sign-in token is kept in a private settings file on that computer and is never shared.
  • No data is sold, shared with or sent to any third party, and no data is used for advertising or analytics.
  • No data is used to develop, improve or train artificial intelligence or machine learning models.

Google API Services User Data Policy

Henry's Dashboard's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can withdraw the app's access at any time from Google Account → Third-party connections. Deleting the app's settings file on the computer removes the stored sign-in token, and the holdings spreadsheet can be deleted from Google Drive like any other file.

Contact

Questions about this policy can be raised through the GitHub repository that hosts this page.
